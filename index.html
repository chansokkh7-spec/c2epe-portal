1

2

Project Settings ⚙️ → Your apps → click </> Web → Copy firebaseConfig

3

Open this HTML in Notepad → find YOUR_API_KEY → paste your config → save

4

Firestore Database → Create database → Test mode → Done

5

Storage → Get started → Test mode → Done
